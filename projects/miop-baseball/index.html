The question

As a freshman on the baseball team, I wanted a program that answered: given this exact situation and this pitcher, what should I be trying to do at the plate? BOA (Batter's Optimal Approach; the original code called it MiOP) was my ENGR 116 final project in Fall 2023, my first semester.

A neural network, built by accident

I didn't know what a neural network was when I wrote BOA. Looking back at the code, that is what I built: a small feed-forward network with hand-set weights. Every input is multiplied by a weight tied to its answer, the results are summed into units with a bias, those units feed the next layer, and the last layer turns numbers into a decision.

Layer by layer, the C++ does this:

  1. Inputs. Runners on 1st, 2nd and 3rd, the number of outs, whether the run gap is closeable, and the pitcher's score.
  2. Hidden layer 1. Two units, location (pull line 0 → opposite line 100) and type (ground ball → fly ball), each starting from a bias of 50. Each input adds its weight: a runner on 2nd adds +20 to location, a runner on 1st adds +7 to type, and the outs count adds +4, +8 or −4. Some inputs act like a hard gate instead (a runner on 3rd sets location to 0).
  3. A step activation. If the run gap is closeable for the inning, both units get +10 ("score" mode); otherwise −10 ("get on base" mode). That is a threshold unit: one comparison decides the sign.
  4. Hidden layer 2. Timing and loft take location and type and subtract the pitcher score ÷ 10, so a harder pitcher means "be earlier, stay on top".
  5. Output. Each number is integer-divided into a bucket (÷14 or ÷25) that indexes a word table. This is a quantised output layer, and it is how the program prints "hit a line drive to the opposite field".

The pitcher score is a neuron of its own. Each pitch is an input, weighted by its speed relative to the fastball, how much it breaks and which way, and the weighted pitches are summed:

What it lacks is the part that makes a network learn: the weights are numbers I picked from baseball intuition, not values fitted to data by gradient descent. The structure is there (weighted sums, biases, a threshold, layers, a decision at the end). The following summer I wrote a network that learns its weights from scratch, the next project in this line.

Known quirks

Integer division means some combinations run past the end of a word table. The original C++ printed an empty string or garbage there, and the demo shows that rather than hiding it.

Deployment

The team-facing version ran on a Linux server: login.cpp opened an SSH session to a dynamic-DNS host, landing each team in its own restricted-shell (rbash) account, with profiles persisted as CSV files.
